Toolkit Overview

Cryptographic Systems Implemented

From ancient substitution ciphers to state-of-the-art authenticated encryption standards used in modern banking and cybersecurity.

Classical Ciphers

Explore the historical origins of cryptography through modular arithmetic mod 26 and polygraphic linear algebra.

  • ● Caesar Cipher: Numerical shift with case preservation
  • ● Multiplicative Cipher: Modular inverse and coprime verification
  • ● Hill Cipher: 2x2 and 3x3 matrix multiplication mod 26

Modern Cryptography

Industry-standard symmetric, asymmetric, hashing, and authentication primitives powered directly by the browser's hardware-accelerated Web Crypto API.

  • ● AES-GCM (128 & 256-bit): Authenticated encryption with fresh IVs
  • ● RSA-OAEP (2048-bit): Asymmetric key generation and encryption
  • ● SHA-256: Cryptographic one-way hashing with avalanche analysis
  • ● HMAC-SHA-256: Message authentication code generation & verification
