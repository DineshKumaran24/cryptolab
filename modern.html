AES-GCM (Authenticated Encryption)

NIST FIPS 197

Working Principle: Advanced Encryption Standard in Galois/Counter Mode (AES-GCM) provides both confidentiality and data authenticity. Generates a fresh cryptographically secure 96-bit Initialization Vector (IV) for every encryption operation. The combined Base64 output packages the IV and ciphertext with its 128-bit authentication tag.

🛡️ Tamper-Evident: If any character of the ciphertext or IV is altered, decryption will immediately fail with an authentication error.

RSA-OAEP (Asymmetric Cryptography)

2048-bit Public Key

Working Principle: Asymmetric cryptography uses two mathematically linked keys: a Public Key (shared openly) to encrypt messages, and a private Private Key (kept secret) to decrypt them. RSA-OAEP with SHA-256 hashing incorporates optimal randomized padding to prevent chosen-ciphertext attacks.

🔒 Asymmetric Assurance: Anyone with your public key can encrypt messages to you, but only you holding the private key can decrypt them.

SHA-256 Cryptographic Hash

NIST FIPS 180-4

Working Principle: Computes a deterministic 256-bit (32-byte, 64-hex character) digest of arbitrary input data. Cryptographic hashing is strictly one-way and non-reversible. Any minor change in input triggers a massive, unpredictable change across the entire digest (the Avalanche Effect).

HMAC-SHA-256 (Message Authentication)

RFC 2104 / RFC 4231

Working Principle: Keyed-hash Message Authentication Code (HMAC) combines a shared secret key with a cryptographic hash function (SHA-256). It guarantees both data integrity and message authenticity: recipients can mathematically verify the sender possessed the shared secret key and the message was not tampered with in transit.
