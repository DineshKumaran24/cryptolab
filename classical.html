Caesar Cipher

Monoalphabetic

Working Principle: Replaces each letter in the plaintext with another letter shifted by a fixed number of positions (k) down the alphabet modulo 26. Case is preserved, and spaces/punctuation remain unchanged.

Multiplicative Cipher

Modular Arithmetic

Working Principle: Multiplies the position of each letter by a key k modulo 26: C = (P × k) mod 26. For decryption to be possible, the key k must be coprime with 26 (i.e. gcd(k, 26) = 1). Decryption uses the modular multiplicative inverse: P = (C × k⁻¹) mod 26.

Hill Cipher (Polygraphic)

Matrix Modulo 26

Working Principle: Groups plaintext into blocks of size N (2 or 3) and multiplies the block vector by an invertible key matrix K modulo 26: C = (K × P) mod 26. Decryption requires computing the modular inverse matrix: K⁻¹ = det(K)⁻¹ × adj(K) mod 26.
